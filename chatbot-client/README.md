# Chatbot Client

This folder will contain the client application for the book understanding chatbot.

## Purpose

This is where you will build the frontend/client interface to interact with the chatbot API.

## Next Steps

You can create:
- Web interface (HTML/CSS/JavaScript)
- Desktop application
- Mobile app
- CLI client
- Or any other client implementation

The client will communicate with the chatbot-api backend to provide users with an interface to chat with the book understanding system.
